# Syed Ahmer Shah | Legacy Portfolio

This repository contains my previous portfolio website. It is no longer actively maintained.

**New Live Website:** [ahmershah.dev](https://ahmershah.dev)  

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **3D Graphics:** Three.js, Blender
- **Performance:** Service Worker caching, lazy loading, responsive images
- **Analytics:** Vercel Web Analytics, Google Tag Manager
- **Deployment:** Static hosting with Git-based workflows

## Features

- Responsive design with dark and light themes
- Interactive 3D elements and project carousel
- Certificate flipbook and contact form
- Accessibility and reduced-motion support
- SEO metadata and structured data
- Performance-focused asset loading and caching

## Run Locally

```bash
git clone https://github.com/ahmershahdev/Portfolio.git
cd Portfolio
python -m http.server 8000
```

Open `http://localhost:8000` in your browser.
